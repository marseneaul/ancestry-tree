# ancestry-tree

## Commands

- `npm run dev` starts the Vite dev server.
- `npm run verify` runs tests, a production build, and the performance budget.
- `npm run perf:budget` checks built asset sizes after `npm run build`.

See [PROFESSIONALIZATION_PLAN.md](./PROFESSIONALIZATION_PLAN.md) for the performance, architecture, and sale-readiness roadmap.
